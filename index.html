    How to use it

    1. Open this page in Microsoft Edge 148 or later (or Chrome 138+). Click Set up engines once. The download takes a while the first time only.
    2. Drop your Word, Excel, PowerPoint or Visio files. Each file is translated, checked and rebuilt in the same format.
    3. Open the review, look at anything flagged, then click Download Spanish file.

    How to prove nothing leaves your computer

    After the engines are set up, turn off Wi-Fi (or unplug the network) and translate a file. It still works. The badge at the top counts every network request made while a file is being translated. It should stay at 0.

    How to read the checks (you don't need to know Spanish)

    • Back-translation score (0–100): a second, independent engine translates the Spanish back to English, and the tool measures how close that is to your original. 70+ means the meaning came back almost word for word. 55–70 means the meaning is usually right but worded differently. Below your threshold, the line is flagged. Short labels (1–3 words) often score low even when correct, so they're only marked "short".
    • Numbers and codes: every amount, date, percentage, account number, code, e-mail and link must appear in the Spanish exactly as in the English. If not, it's an error.
    • Glossary: terms set to "Translate as" must use your Spanish term. Terms set to "Keep as is" must appear unchanged.
    • Untranslated / length: flags text left in English and lines that came out much shorter or longer than expected (a sign that something was dropped or added).

    Working with a Spanish-speaking colleague

    Click Export review sheet. It's an Excel file with English, Spanish, back-translation, score and flags. Your colleague fills in Corrected Spanish or marks Approved = Y. Import it back with Import reviewed sheet, then Rebuild file. Their corrections go into the translation memory and are reused in every future document.

    Good to know

    • If a paragraph mixes formatting (for example, one bold word in the middle), the translated paragraph takes the formatting of its first run. Headings, tables, lists and styles are not affected.
    • Excel: cell text is translated. Formulas, numbers and sheet names are not. If a formula looks up a text value (like "Yes"), check it after translation. The review lists those workbooks.
    • Word page count: Word recalculates pages when you open the file. The figure shown here is an estimate.
    • After a large glossary change, use Translation memory → Forget machine lines, so older lines are translated again with the new terms.
